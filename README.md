## Featured Projects

### [FocusGuard](https://github.com/AnshParmar123/FocusGuard)

A browser-based phone detection app that uses AI in real time through the webcam. It detects phones in the frame, draws live bounding boxes, and triggers an alert workflow directly in the browser.

**Highlights:** TensorFlow.js, COCO-SSD, webcam detection, frontend product UX, Vercel-friendly deployment.

### [Synthetic Persona Bias Auditing with DCGAN](https://github.com/AnshParmar123/synthetic-persona-bias-auditing-dcgan)

A research-driven GAN project that generates synthetic human faces and audits demographic skew by comparing real and generated attribute distributions.

**Highlights:** PyTorch, DCGANs, fairness analysis, synthetic data evaluation, research presentation workflow.

### [Portfolio Website](https://github.com/AnshParmar123/ansh-portfolio-website)

My personal portfolio space for presenting work in AI, machine learning, and development through a more polished and personal interface.

**Highlights:** personal branding, frontend development, project storytelling, design-focused presentation.
